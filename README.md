# Game-Alitaptap

About the Game
- Alitaptap is a Filipino-based riddle adventure game inspired by bugtong. Players explore a story-driven world where every puzzle is part of a journey.

Core Concept
- Solve Filipino bugtong (riddles)
- Progress through a story-based world
- Unlock paths using correct answers
- Follow alitaptap (fireflies) as guides of light and clues

Goal
- To make learning Filipino words and riddles fun through exploration and storytelling.
